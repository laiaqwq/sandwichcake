`sandwichcake completion <shell>` prints a shell autocompletion script
to stdout — each shell is a subcommand: `bash`, `zsh`, `fish`,
`powershell`.

The script is generated by cobra, so completions cover every command,
subcommand and flag dynamically — including `pack <type>` names and
global flags. Each subcommand accepts `--no-descriptions`; the bash
script requires the `bash-completion` package, and flag-value
completion falls back to filenames (no custom completers registered).

## Examples

```sh
# zsh (macOS homebrew; Intel: /usr/local/share/zsh/site-functions)
sandwichcake completion zsh > "$(brew --prefix)/share/zsh/site-functions/_sandwichcake"

# bash (linux)
sandwichcake completion bash | sudo tee /etc/bash_completion.d/sandwichcake

# fish
sandwichcake completion fish > ~/.config/fish/completions/sandwichcake.fish

# powershell — add to your profile
sandwichcake completion powershell >> $PROFILE
```

Restart the shell (or `source` the file) to activate. If the binary was
installed as `swcake`, generate completions under that name instead so
the right command is completed.
