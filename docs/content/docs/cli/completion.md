Print a shell autocompletion script to stdout.

## Synopsis

```text
sandwichcake completion bash [--no-descriptions]
sandwichcake completion zsh [--no-descriptions]
sandwichcake completion fish [--no-descriptions]
sandwichcake completion powershell [--no-descriptions]
```

## Flags

| Flag | Description |
|------|-------------|
| `--no-descriptions` | Complete names only, without help text |

Plus the [global flags](_index.md#global-flags).

## What happens

The script is generated by cobra, so completions cover every command,
subcommand and flag — including `pack <type>` names and global flags.
The bash script requires the `bash-completion` package; flag values
complete as file names (there are no custom completers).

## Examples

```sh
# zsh (macOS Homebrew; Intel: /usr/local/share/zsh/site-functions)
sandwichcake completion zsh > "$(brew --prefix)/share/zsh/site-functions/_sandwichcake"

# bash (Linux)
sandwichcake completion bash | sudo tee /etc/bash_completion.d/sandwichcake

# fish
sandwichcake completion fish > ~/.config/fish/completions/sandwichcake.fish

# PowerShell — add to your profile
sandwichcake completion powershell >> $PROFILE
```

Restart the shell (or `source` the file) to activate. If you call the
binary as `swcake`, generate the script with `swcake completion …` so
the completions are registered under that name.
